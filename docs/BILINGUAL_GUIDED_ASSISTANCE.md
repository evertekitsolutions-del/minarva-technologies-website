# Minarva Technologies website — Malayalam/English service guidance

Scope: public website `www.minarvatechnologies.com/assistant`. **Not Minarva Biz**.

This page is a deterministic, free, local-browser guide — **not a generative AI model**. It does not query a customer database, reveal work-order details, or send typed questions to any provider. A visitor may:

1. Select English or മലയാളം.
2. Choose one of seven service categories or describe a requirement in either language.
3. Follow the most relevant service link(s) to a quotation/enquiry page.
4. Contact human support if the requirement is ambiguous or no safe match exists.

For a question involving both CCTV and Wi-Fi the page offers both services; no attempt is made to invent a definitive diagnosis. Typed details do not transfer automatically to an enquiry form. Do not add any paid chat provider or real outbound calling in this milestone.

**Verification:** `tools/guided-assistance-integrity.mjs` (source/privacy invariants), `tools/bilingual-guide-browser-qa.mjs` (Malayalam, English, ambiguity, no-match human handoff, reset, responsiveness) integrated with the existing `Public Website Cross-Device E2E` workflow.

Still not delivered without consent and account verification: authenticated customer job status, genuine LLM-powered assistant, public production voice/calling, Google Search Console activation, customer reviews or project portfolio.
